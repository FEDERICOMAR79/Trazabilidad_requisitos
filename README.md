# Trazabilidad de requisitos

Repositorio de artefactos de la asignatura Ingenieria de Requisitos (Vision Board, Product Backlog, SRS, modelos, prototipos y matrices de trazabilidad), versionados con Git.

Cada proyecto vive en su propia rama. Esta rama (`main`) solo presenta el repositorio.

## Proyectos

| Rama | Proyecto |
| --- | --- |
| `dietas` | Dietas al Dia |
| `mudanzas` | Portal Web de Transporte de Carga |
| `simulador` | Simulador de Transmision Mecanica |
| `tripulaciones` | Sistema Integral de Gestion de Tripulaciones |
